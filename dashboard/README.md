# Alpaca AI Trading Agent Dashboard

A minimal Streamlit dashboard for monitoring the autonomous options trading agent.

## Features

- **Portfolio Overview**: Account equity, cash, buying power, portfolio value
- **Positions**: Current open positions with P&L and Greeks
- **Trading Activity**: Order history, signal frequency, recent decisions
- **Agent Reasoning**: Complete decision chain audit trail (market state → features → signals → AI → risk → execution → results)
- **Live Activity Timeline**: Real-time view of recent trading decisions
- **Auto-refresh**: Updates every 30 seconds for live data

## Data Sources

The dashboard reads from:
- **SQLite Database** (`data/agent.db`): Decision journal and orders tables
- **Alpaca API** (when connected): Live account and position data

## Setup Instructions

### 1. Install Dependencies
```bash
pip install streamlit pandas
```

> **Note**: If you encounter Starlette compatibility issues, you may need to:
> ```bash
> pip install --upgrade streamlit
> # or
> pip install "streamlit==1.29.0" "starlette==0.27.0"
> ```

### 2. Configure Environment
Ensure your `.env` file contains:
```
ALPACA_API_KEY=your_paper_trading_key
ALPACA_SECRET_KEY=your_paper_trading_secret
ALPACA_PAPER=true
TRADING_ENABLED=true
AI_ENABLED=true  # Optional: enables AI supervision layer
```

### 3. Run the Dashboard
```bash
streamlit run dashboard/app.py
```

### 4. Access the Dashboard
Open your browser to: http://localhost:8501

## Dashboard Tabs

### 📊 Portfolio
- Real-time account metrics (when Alpaca API connected)
- Demo data shown when API not configured
- Equity, cash, buying power, portfolio value
- Account status and trading enabled/disabled flags

### 📋 Positions
- Current open positions
- Symbol, quantity, side, entry/current prices
- Market value, unrealized P&L, P&L percentage
- Shows "no positions" when markets are closed or no trades executed

### 📝 Trades & Signals
- Order execution history
- Recent trading signals and AI decisions
- Signal frequency chart (last 24 hours)
- Trade volume and timing analysis

### 🧠 Agent Reasoning
- **Complete decision chain audit trail** for each decision
- Expandable sections showing:
  - Market state & features
  - Strategy signal generation
  - AI reasoning (decision, confidence, thesis, risks)
  - Risk assessment (approved/rejected with reasons)
  - Execution details (if trade executed)
  - Trade results (position details or rejection reasons)
- Timeline view of recent decisions

## Data Privacy & Security
- All data is read-only; dashboard cannot execute trades
- No sensitive API keys stored or logged
- Runs locally; data never leaves your machine
- Uses Alpaca paper trading by default (no real money at risk)

## Customization

### Adjust Refresh Rate
Modify the JavaScript auto-refresh in `dashboard/app.py`:
```javascript
setTimeout(function(){
    window.location.reload();
}, 30000); // 30 seconds - change value to adjust
```

### Change Appearance
Modify Streamlit configuration in `.streamlit/config.toml`:
```toml
[theme]
primaryColor="#FF6B35"
backgroundColor="#FFFFFF"
secondaryBackgroundColor="#F0F2F6"
textColor="#262730"
font="sans serif"
```

## Troubleshooting

### "Cannot import streamlit" Error
```bash
pip install --upgrade streamlit
```

### Starlette Compatibility Issues
```bash
# Option 1: Upgrade Streamlit
pip install --upgrade streamlit

# Option 2: Pin specific versions (RECOMMENDED)
pip install "streamlit==1.29.0" "starlette==0.27.0"

# Option 3: Use virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
pip install streamlit pandas
```

### DateTime Comparison Errors
If you see errors like:
- `TypeError: Invalid comparison between dtype=datetime64[us, UTC] and datetime`
- `ValueError: Invalid frequency: H. Failed to parse with error message: KeyError('H')`

These have been fixed in the current version. Please ensure you have the latest version of the dashboard code. If you encounter similar issues:
1. Make sure you're using the pinned dependencies: `streamlit==1.29.0` and `pandas==2.2.0`
2. The code has been updated to use timezone-aware datetime comparisons and lowercase 'h' for frequency

### Database Access Issues
- Ensure `data/agent.db` file exists and is readable
- Check that the trading system has created journal entries
- Run the trading agent first to generate data: `python -m backend.scripts.run_paper_cycle`

### No Live Data Showing
- Verify Alpaca API keys are correct in `.env`
- Ensure `TRADING_ENABLED=true` in `.env`
- Check that markets are open (weekdays 9:30 AM - 4:00 PM ET)
- Confirm the trading agent is running and generating signals

## Algorithm Transparency
This dashboard implements the full audit trail as specified in the Alpaca AI Trading Agent build plan:
- **Quantitative Signals**: Generated by strategy engine (Liquid Momentum, etc.)
- **AI Supervision**: Provides contextual validation and explainable reasoning
- **Risk Engine**: Final authority on trade approval (safety critical)
- **Execution Layer**: Handles order submission and position tracking
- **Decision Journal**: Complete record of every decision point

This provides regulators, auditors, and team members with complete visibility into how trading decisions are made.
